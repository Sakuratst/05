第五次作业
问题一：- 生产者线程：队列已满时，调用`cv.wait(lock, [&]{return !queue.full();})`，释放锁并阻塞当前线程，等待消费者取出数据、队列有空位后被唤醒。
- 消费者线程：队列为空时，调用`cv.wait(lock, [&]{return !queue.empty() || is_closed;})`，释放锁阻塞线程，等待生产者放入数据或者队列标记关闭后唤醒。
- 问题二：队列为空并且生产者计数为0
- 问题三：关闭只是不再接收新的数据，需要消费者把残留数据完成时间戳匹配输出完整结果
- 问题四：1. 别缓存 IMU 数据包，一般将 IMU 数据存入有序列表（按时间戳升序）；
2. 依次取出每一个相机数据包，拿到相机时间戳；
3. 在有序 IMU 序列中，二分查找找到相机时间戳插入位置，对比插入点前后两个 IMU 时间戳，选出时间差绝对值最小的 IMU 包；
4. 计算时间差，如果找到匹配对则输出匹配信息；找不到则标记`UNMATCHED`；
5. 把匹配结果写入输出文件。
复杂度

- 预处理：IMU 有序存储 \(O(n)\)；
- 单次相机包匹配：二分查找 \(O(\log M)\)，M 为 IMU 缓存条数；
- 总复杂度：\(O(N \log M)\)，N 是相机数据包总数。
- 问题五：1.完全相等：直接匹配，时间差 delta=0，优先选中这条 IMU。
- 2.绝对时间差相同：约定选择时间戳更小的 IMU 包；也可以根据需求选择时间戳更大的，代码里固定一套规则即可，需要注释说明规则。
- 3.IMU 数据不足：相机包没有任何 IMU 可以匹配，输出`UNMATCHED`。
- 4.重复相同时间戳数据包：保留全部数据包，匹配时按上面规则选择；可增加序号作为次级排序键，保证结果确定性。
- 问题六：- 不直接暴力终止进程；捕获异常，将生产者计数减 1；触发条件变量通知，唤醒等待中的消费者和其他生产者
